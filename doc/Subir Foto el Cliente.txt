========================================================================================================================================================================================================================================================================================================================

Para ir sobre seguro y ver resultados desde el primer día sin enredarnos, el orden más lógico y didáctico de construcción es este:

1. Paso 1 — El motor automático en GitHub (GitHub Actions): Empezamos por aquí porque puedes probarlo tú mismo subiendo una foto cualquiera al repositorio. Verás cómo GitHub la convierte solo a las 7 variantes (480, 960, 1204 en .avif y .jpg), cambia el texto y actualiza width/height y el alt en tu index.html.
2. Paso 2 — La caché de la PWA: Una vez que el HTML cambia solo, revisamos tu Service Worker (o archivo de versión) para asegurarnos de que cuando un móvil abra la web, descargue la foto nueva sin quedarse atascado en la de ayer.
3. Paso 3 — El puente seguro (Cloudflare Worker): Creamos un pequeño intermediario gratuito para que se pueda subir la foto y el texto desde fuera sin tener que entrar en GitHub.
4. Paso 4 — La pantalla móvil para el frutero: Por último, hacemos una página limpia y grande para el móvil (con botón de cámara, vista previa y campo de texto) conectada al puente del Paso 3.

========================================================================================================================================================================================================================================================================================================================

Paso 1.1: Crea la rama pruebas-auto en VS Code

1. En tu VS Code, haz clic abajo a la izquierda donde pone main (junto al icono de ramas).
2. Selecciona Crear nueva rama... (Create new branch...), llámala pruebas-auto y pulsa Enter.
3. Publica la rama en GitHub haciendo clic en el icono de nube/sincronizar de abajo a la izquierda.

Paso 1.2: Crea los 3 archivos del motor


Archivo 1: scripts/package.json

Crea una carpeta llamada scripts en la raíz de tu proyecto y dentro mete este archivo para indicar las dos herramientas que usará Node.js (sharp para las imágenes y cheerio para editar el HTML):

{
  "name": "fruteria-automatizacion",
  "private": true,
  "type": "module",
  "dependencies": {
    "cheerio": "^1.0.0",
    "sharp": "^0.33.5"
  }
}


Archivo 2: scripts/actualizar.js

Dentro de la misma carpeta scripts, crea actualizar.js. Este es el cerebro que lee la foto y el texto que subas a la carpeta entrada/, genera las 7 fotos en img/ y actualiza tu index.html:

import fs from 'node:fs/promises';
import path from 'node:path';
import sharp from 'sharp';
import * as cheerio from 'cheerio';

const ENTRADA_DIR = 'img/sugerencias';
const IMG_DIR = 'img';
const HTML_FILE = 'index.html';

async function main() {
  const archivos = await fs.readdir(ENTRADA_DIR);
  const fotoArchivo = archivos.find((f) => /\.(jpe?g|png|webp|heic|heif|avif)$/i.test(f));
  const textoArchivo = archivos.find((f) => f === 'descripcion.txt');

  if (!fotoArchivo && !textoArchivo) {
    console.log('No hay archivos nuevos en img/sugerencias/. Saliendo.');
    return;
  }

  let anchoFinal = null;
  let altoFinal = null;

  // 1. Si hay foto nueva, generar las 7 variantes
  if (fotoArchivo) {
    const rutaFoto = path.join(ENTRADA_DIR, fotoArchivo);
    const imagenBase = sharp(rutaFoto).rotate();
    const tamanos = [480, 960, 1204];

    for (const ancho of tamanos) {
      await imagenBase
        .clone()
        .resize({ width: ancho, withoutEnlargement: false })
        .avif({ quality: 69 })
        .toFile(path.join(IMG_DIR, `sugerencia-del-dia-${ancho}.avif`));

      const infoJpg = await imagenBase
        .clone()
        .resize({ width: ancho, withoutEnlargement: false })
        .jpeg({ quality: 88, mozjpeg: true })
        .toFile(path.join(IMG_DIR, `sugerencia-del-dia-${ancho}.jpg`));

      if (ancho === 1204) {
        anchoFinal = infoJpg.width;
        altoFinal = infoJpg.height;
        await fs.copyFile(
          path.join(IMG_DIR, 'sugerencia-del-dia-1204.jpg'),
          path.join(IMG_DIR, 'sugerencia-del-dia.jpg')
        );
      }
    }

  }

  // 2. Actualizar index.html
  const htmlOriginal = await fs.readFile(HTML_FILE, 'utf-8');
  const $ = cheerio.load(htmlOriginal, { decodeEntities: false });

  if (textoArchivo) {
    const rutaTexto = path.join(ENTRADA_DIR, textoArchivo);
    const contenido = await fs.readFile(rutaTexto, 'utf-8');
    if (contenido.trim()) {
      $('#fruteria-sugerencia').text(contenido.trim());
    }
  }

  if (anchoFinal && altoFinal) {
    const $img = $('#fruteria-foto img');
    $img.attr('width', String(anchoFinal));
    $img.attr('height', String(altoFinal));
  }

  await fs.writeFile(HTML_FILE, $.html(), 'utf-8');

  // 3. Actualizar la versión de caché en service-worker.js
  const swPath = 'service-worker.js';
  const swContenido = await fs.readFile(swPath, 'utf-8');
  const marcaTiempo = new Intl.DateTimeFormat('sv-SE', {
  timeZone: 'Europe/Madrid',
  year: 'numeric',
  month: '2-digit',
  day: '2-digit',
  hour: '2-digit',
  minute: '2-digit',
  second: '2-digit'
  }).format(new Date()).replace(/[-: ]/g, '');

  const swActualizado = swContenido.replace(
    /const CACHE_NAME = "fruteria-del-terreno-[^"]+";/,
    `const CACHE_NAME = "fruteria-del-terreno-${marcaTiempo}";`
  );
  await fs.writeFile(swPath, swActualizado, 'utf-8');

  // 4. Limpiar TODOS los archivos temporales de img/sugerencias/ (dejando solo .gitkeep)
  const restantes = await fs.readdir(ENTRADA_DIR);
  for (const archivo of restantes) {
    if (archivo !== '.gitkeep') {
      await fs.unlink(path.join(ENTRADA_DIR, archivo));
    }
  }

  console.log('Actualización completada y carpeta img/sugerencias limpia.');
}

main().catch((err) => {
  console.error(err);
  process.exit(1);
});

Archivo 3: .github/workflows/actualizar-sugerencia.yml

Crea la carpeta .github (con un punto delante), dentro workflows, y dentro el archivo actualizar-sugerencia.yml:

name: Actualizar sugerencia del día

on:
  push:
    branches:
      - subir-foto
    paths:
      - 'img/sugerencias/**'

permissions:
  contents: write

jobs:
  procesar:
    runs-on: ubuntu-latest
    steps:
      - name: Descargar repositorio
        uses: actions/checkout@v4

      - name: Configurar Node.js
        uses: actions/setup-node@v4
        with:
          node-version: '20'

      - name: Instalar dependencias (sharp y cheerio)
        working-directory: ./scripts
        run: npm install

      - name: Convertir foto y actualizar HTML
        run: node scripts/actualizar.js

      - name: Guardar cambios en el repositorio
        run: |
          git config --local user.email "bot@fruteriadelterreno.com"
          git config --local user.name "Robot Frutería"
          git add -A
          git commit -m "chore: actualizar sugerencia del día automáticamente" || exit 0
          git push


Paso 1.3: ¡La prueba de fuego!

1. Crea una carpeta llamada entrada en la raíz de tu proyecto.
2. Mete dentro cualquier foto tuya (por ejemplo prueba.jpg) y un archivo de texto descripcion.txt con una frase nueva (ej. 🍊🍊Naranjas recién cogidas del árbol hoy mismo🍊🍊).
3. Haz Commit y Push a la rama pruebas-auto.
4. Entra en tu repositorio en GitHub.com -> pestaña Actions y mira cómo el robot trabaja en directo (tardará unos 25 segundos). Al terminar, haz Pull en VS Code y verás tus 7 fotos nuevas en img/ y tu index.html actualizado solo.
(Importante: verifica en GitHub.com -> Settings > Actions > General > Workflow permissions que esté marcada la casilla Read and write permissions).
Pruébalo en tu rama pruebas-auto y dime qué tal sale la ejecución en la pestaña Actions de GitHub.
